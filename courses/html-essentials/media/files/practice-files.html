Unit 1 · The anatomy of a web page

Build the page skeleton

Mia’s page only has body content. Turn it into a complete HTML5 page.

  1. Start with the doctype
  2. Wrap everything in <html> with lang="en-AU"
  3. Add a <head> with the character set and a title
  4. Keep one <h1> and the paragraph inside <body>
Starter unit1-page-skeleton.html
<h1>Leave policy update</h1>
<p>From 1 July, you can request leave through the staff portal.</p>
Show the solution
Solution
<!doctype html>
<html lang="en-AU">
  <head>
    <meta charset="utf-8">
    <title>Leave policy update – Staff portal</title>
  </head>
  <body>
    <h1>Leave policy update</h1>
    <p>From 1 July, you can request leave through the staff portal.</p>
  </body>
</html>

Unit 2 · Headings, text and semantic structure

Structure the news page

Give this page landmarks and a proper heading outline.

  1. Put the site title in a <header> as the <h1>
  2. Put both stories in <main>, each with an <h2>
  3. Put the copyright line in a <footer>
  4. Mark “Entries close Friday” as important with <strong>

Unit 3 · Links and images

Fix the careers page

This page has a vague link and two images without alt text. Fix them.

  1. Change the link text to describe where it goes (not “click here”)
  2. Make the link go to https://example.com/careers
  3. Give the team photo a meaningful alt
  4. The divider line is decorative: give it an empty alt, alt=""
  5. Give the photo width and height attributes
Starter unit3-careers-page.html
<!doctype html>
<html lang="en-AU">
  <head>
    <meta charset="utf-8">
    <title>Careers – Shammim</title>
  </head>
  <body>
    <h1>Work with us</h1>
    <img src="images/team-photo.jpg">
    <img src="images/divider.svg">
    <p>We’re hiring a content designer. <a href="">Click here</a>.</p>
  </body>
</html>

Unit 4 · Lists and tables

Make the roster accessible

Turn Priya’s roster into an accessible data table.

  1. Add a <caption> that names the table
  2. Put the header row in <thead> with <th scope="col"> cells
  3. Put the other rows in <tbody>
  4. Make each day a row header: <th scope="row">
Starter unit4-roster-table.html
<!doctype html>
<html lang="en-AU">
  <head>
    <meta charset="utf-8">
    <title>Help desk roster</title>
    <style>table{border-collapse:collapse}th,td{border:1px solid #6F8C87;padding:6px 10px;text-align:left}caption{font-weight:bold;text-align:left;padding-bottom:6px}</style>
  </head>
  <body>
    <h1>Help desk roster</h1>
    <table>
      <tr><td>Day</td><td>Morning</td><td>Afternoon</td></tr>
      <tr><td>Monday</td><td>Sam</td><td>Priya</td></tr>

      <tr><td>Wednesday</td><td>Priya</td><td>Sam</td></tr>

Unit 5 · Accessible forms

Build an accessible feedback form

Fix the event feedback form so every field is labelled and it can be sent with a keyboard.

  1. Give the name and email fields visible labels linked with for and id
  2. Make the email field type="email" and required
  3. Group the rating radio buttons in a <fieldset> with a <legend>
  4. Replace the <div> with a <button type="submit">
Starter unit5-feedback-form.html
<!doctype html>
<html lang="en-AU">
  <head>
    <meta charset="utf-8">
    <title>Event feedback</title>
  </head>
  <body>
    <h1>Event feedback</h1>
    <form>
      <p><input type="text" id="name" placeholder="Name" autocomplete="name"></p>
      <p><input type="text" id="email" placeholder="Email" autocomplete="email"></p>
      <p>How useful was the event?</p>
      <p>
        <input type="radio" id="r1" name="rating" value="1"><label for="r1">Not useful</label>
        <input type="radio" id="r2" name="rating" value="2"><label for="r2">Useful</label>
        <input type="radio" id="r3" name="rating" value="3"><label for="r3">Very useful</label>
      </p>
      <div class="btn">Send feedback</div>
    </form>
  </body>
</html>
