Engaging learning experience

  • Three choices, each played out in the staffroom
  • A debrief that explains every option
  • Private reflection that is never stored or scored

Technical stack

  • Custom HTML5, CSS and JavaScript course build
  • Shared scenario engine on one page that runs offline
  • Illustrated characters
  • Browser speech for optional voices

Accessibility
