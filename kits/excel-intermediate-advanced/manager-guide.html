Manager embedding guide

Microsoft Excel: Intermediate to Advanced skills program
Staff who already use Excel every week

Learning only changes practice when it is used, noticed and reinforced on the job. This guide gives you three short conversations and a simple plan.

What your team member will learn

  • Structure data as Excel Tables with validation so it stays reliable
  • Look up and summarise data with XLOOKUP, dynamic arrays and PivotTables
  • Answer what-if questions with Goal Seek and scenarios
  • Protect and share workbooks safely, and automate a repetitive task

Before the program (10 minutes)

  • Which workbook causes the team the most problems?
  • What would you like to be able to do in Excel?
  • How much time can you protect for practice?

After the program (15 minutes)

  • Show me the workbook you improved. What changed?
  • Where could this save the team time?
  • What will you tackle next?

What good looks like on the job

  • Structures data as a named Table
  • Uses validation on key columns
  • Uses XLOOKUP or a PivotTable appropriately
  • Applies a what-if tool to a real question
  • Shares the file safely
