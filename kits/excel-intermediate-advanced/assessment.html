Part A · Multiple choice

Choose the best answer.

1. Your SUM misses rows added below the data. What is the best fix?
  1. Rewrite the SUM each time
  2. Convert the data to an Excel Table and use structured references
  3. Add blank rows in advance
  4. Use a bigger range
2. Which function returns a value from another column by matching a code, with a not-found message?
  1. VLOOKUP only
  2. XLOOKUP
  3. SUMIF
  4. COUNTA
3. A formula shows #SPILL!. What does it mean?
  1. The formula is wrong
  2. The result range is blocked by existing data
  3. Excel has crashed
  4. The file is protected
4. Which tool finds the input needed to reach a target result?
  1. Goal Seek
  2. Flash Fill
  3. Conditional formatting
  4. Freeze Panes
5. Before sharing a workbook that contains sensitive data, what should you do?
  1. Hide the columns
  2. Remove or protect the sensitive data and check sharing permissions
  3. Change the font colour to white
  4. Rename the file

Marking guide (for assessors)

Part A answers

  1. B. Convert the data to an Excel Table and use structured references Tables expand automatically, and formulas using them update.
  2. B. XLOOKUP XLOOKUP looks up in any direction and has a built-in if-not-found argument.
  3. B. The result range is blocked by existing data Dynamic array results need empty cells to spill into.
  4. A. Goal Seek Goal Seek works backwards from a target value.
  5. B. Remove or protect the sensitive data and check sharing permissions Hiding is not protection; remove data or restrict access.

Part B model answers

  1. They expand automatically, keep formatting and formulas consistent, and use readable structured references.
  2. To summarise large data quickly by category or date, explore different views, and add slicers for others.

Part C: look for

  • Sets up the inputs and formula clearly
  • Uses Goal Seek or a scenario correctly
  • Checks the result makes sense
  • Presents the answer clearly

Result: all Part D criteria observed, and Parts A to C answered to the standard above. Where something is not yet shown, give feedback and agree a time to reassess.
